# Кимпаб — рабочий макет

Макет корейского гриль-бара в Гатчине для обсуждения с заказчиком.

Адрес GitHub Pages: https://x1nnon.github.io/portfolio/concepts/kimpab/
Сайт работает как статическая страница, сборка не требуется.

## Что готово

- Сохранены тёмный графит, красный акцент, текстовый знак и главный заголовок исходного макета.
- Локальный Golos Text, адаптация на 320–1440 px, клавиатурная навигация и reduced motion.
- Каталог по примеру «Рестобара 1715»: 35 позиций в шести разделах, 18 фотокарточек с составом, порцией и ценой; остальные позиции компактным списком.
- 20 новых изображений, сгенерированных встроенным ImageGen по блюдам из оригинального меню. Все фотографии страницы локальные, с адаптивными WebP для разных экранов.
- Самостоятельные разделы о гриль-баре, обедах по будням 12:00–15:00, семейном визите и бронировании столов.
- Пояснение, как устроен самгёпсаль, детские блюда с ценами, новости сообщества, копирование адреса.
- Реальные названия, цены и вес из PDF, опубликованного в закреплённой записи ВК.
- Шесть наборов самгёпсаля: три вида мяса, по 4 и 6 гостей.
- Просмотр всех 28 страниц меню без входа в ВК: разделы, переключение страниц, крупный просмотр, скачивание PDF.
- Кнопки звонка, прямой переход в сообщения сообщества и ссылка на карту.
- Постоянная мобильная панель «Меню / Позвонить», скрывающаяся возле блока контактов.
- Ответы на вопросы о бронировании, остроте, детском и полном меню.
- Изображения из исходного PDF используются только внутри просмотрщика полного меню. Главный экран, карточки блюд и гриль используют новые генерации.
- Старые материалы оставлены в assets как исходники; на странице не используются.

## Файлы

index.html — структура и начальное содержимое.
style.css — оформление.
menu-data.js — 35 позиций каталога; названия, состав, вес, цена, источник-страница.
app.js — переключатели, просмотр меню, мобильные действия.
assets/menu.pdf — оригинальный файл из закреплённой записи.
assets/menu-pages — 28 изображений страниц для просмотра.
assets/generated — новые фотографии в WebP; полные исходники генераций остаются локально и исключены из Git.
IMAGE-PROMPTS.json — полный набор промптов и соответствие референсным страницам меню.
SOURCES.md — происхождение материалов и ограничения.

## Проверки

Локальные проверки выполнялись в отдельном headless Edge с чистым профилем; запросы разрешены только к localhost. Пользовательская сессия браузера не использовалась.
Проверены переключатели всех шести разделов, 35 позиций и 18 уникальных фотокарточек, стрелки/Home/End, просмотр PDF-страниц, крайние страницы, Escape, FAQ, якоря, копирование адреса, загрузка всех 20 изображений, отсутствие ошибок JavaScript и горизонтального переполнения на 320, 390, 600, 768, 1024 и 1440 px. Проверка Lighthouse сохранена в отчётах.
Снимки, отчёты проверок и резервные копии хранятся локально.

## Перед отправкой и запуском

Цены и часы взяты из публичных материалов, но ещё не подтверждены владельцем. Сгенерированные изображения иллюстрируют блюда для макета; фактическую подачу надо согласовать. Верхняя кнопка «Меню» в ВК ведёт на недоступный файл: использовано меню из закреплённого поста.
Нет заявок, оплаты, корзины, аналитики и сбора персональных данных. Бронь подтверждается заведением по телефону или в ВК.
Перед запуском рабочего сайта подтвердить материалы у владельца, выбрать домен и хостинг, добавить сведения о владельце сайта. Для макета на GitHub Pages сохранён noindex.

Итоговый Lighthouse (эмуляция мобильного устройства, локальный preview): Performance 96, Accessibility 100, Best Practices 100. LCP 2,7 с, CLS 0. Это локальная проверка, не полевые метрики публичного хостинга.
